# Link Saver

Save links into folders, watch videos in-app, and export or share your folders.

## Run
1. Open the `link-saver` folder in VS Code.
2. Install the **Live Server** extension, right-click `index.html`, choose **Open with Live Server**.
   (Use Live Server, not a double-click: YouTube embeds need an http:// address.)

## Structure
link-saver/
  index.html
  css/style.css
  js/app.js
  README.md

Data is stored in your browser (localStorage). Use Export & share to move it between devices.
